BlockViz Python backend - Astra connection contract

Imports and session:

from astra_connect.connect import get_session
session = get_session()  # uses ASTRA_TARGET (main by default)

What get_session() guarantees:

- Loads .env automatically (repo root, backend/.env, or DOTENV_FILE override).
- Resolves target-specific config:
  - main: ASTRA_TOKEN, ASTRA_BUNDLE_NAME, ASTRA_KEYSPACE
  - backup: ASTRA_TOKEN_BACKUP, ASTRA_BUNDLE_NAME_BACKUP, ASTRA_KEYSPACE_BACKUP
  - selector: ASTRA_TARGET=main|backup
- Resolves secure bundle path from:
  - ASTRA_BUNDLE_PATH (folder path) + ASTRA_BUNDLE_NAME[_BACKUP]
  - or backward-compatible direct zip path in ASTRA_BUNDLE_PATH.
- Applies request/connect/fetch settings:
  - REQUEST_TIMEOUT_SEC (default 60)
  - CONNECT_TIMEOUT_SEC (default 15)
  - FETCH_SIZE (default 1000)

Options:

- get_session(target="main"|"backup") to override ASTRA_TARGET.
- get_session(keyspace="...") to override keyspace.
- get_session(return_cluster=True) -> (session, cluster) for explicit shutdown.
- get_session(override_env_with_dotenv=True) to let .env override shell vars.

Shutdown pattern:

session, cluster = get_session(return_cluster=True)
try:
    ...
finally:
    cluster.shutdown()

Avoid per-script env/path hacks; use astra_connect.connect as the single source of truth.
